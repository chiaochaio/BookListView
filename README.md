## 這是**圖書館借還書**系統：
* **可雙擊點選借閱或還書**
* **會顯示已借閱清單**
* **會顯示已借閱清單**
* **可調整檢視方式**
* **可自由挑整視窗大小**<br><br>

## **功能介紹**：
1. **雙擊**：當雙擊某一書本時可以 **借閱或還書**。<br>

2. **各種檢視方式**：按下 **下拉選單** 後，可自由選取。<br>
<img width="325" height="294" alt="image" src="https://github.com/user-attachments/assets/2d842cb6-3941-4fcb-895f-256dbd69f475" /><br>
